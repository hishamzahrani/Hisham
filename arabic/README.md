# رحلة الضاد — تطبيق علوم العربية

تطبيق تعليمي باللغة العربية لمن هم في **الخامسة عشرة فما فوق**. يضم **سبعة علوم** و**31 درسًا** و**188 تمرينًا**. في كل درس شرح موجز بالأمثلة (من القرآن الكريم والشعر وكلام العرب)، ثم تمارين.

| العلم | الدروس |
|---|---|
| النحو | الكلام وأقسامه · المعرب والمبني · المبتدأ والخبر · النواسخ · الفاعل ونائبه والمفعول به · المنصوبات · التوابع |
| الصرف | الميزان الصرفي · الصحيح والمعتل والمجرد والمزيد · المشتقات · المصادر · الإعلال والإبدال |
| البلاغة | الفصاحة والبلاغة · البديع المعنوي · البديع اللفظي |
| علم المعاني | الخبر وأضربه · الإنشاء الطلبي وأغراضه · القصر · الإيجاز والإطناب والفصل والوصل |
| علم البيان | التشبيه · الاستعارة · المجاز المرسل · الكناية |
| فقه اللغة | اللغة ونشأتها وأعلامها · الظواهر اللغوية · خصائص العربية وأصواتها · المعاجم العربية |
| معاني المفردات | غريب الألفاظ · الفروق اللغوية · أسماء الصغار والأصوات والمساكن · أخطاء شائعة |

## الرحلة
الصفحة الرئيسية خريطة رحلة على طريقة «مسابقات قرآنية»، لكن في صورة خط سير:
- كل علم **محطة** (٧ محطات)، ودروسه **مراحل فرعية** يمشي بينها المسافر 🚶 على درب منقّط.
- في آخر كل محطة **اختبار المحطة** (١٠ أسئلة، والنجاح ٧٠٪). فإذا اجتازه ركب وسيلة نقل إلى المحطة التالية، بالتناوب: **السفينة** 🚢 في البحر، ثم **الحافلة** 🚌 على الطريق، ثم **القطار** 🚆 على السكة. والرحلة تنتهي عند **خط الوصول** 🏁.
- عند العودة إلى الخريطة بعد إنهاء درس أو اختبار يتحرك المسافر أو المركبة على المسار حتى المرحلة الجديدة.
- ترتيب وسائل النقل في `VEH` داخل `app.js`.

## المزايا
- **٥ قلوب** مشتركة: كل خطأ في درس أو اختبار محطة يُنقص قلبًا، وتمتلئ كلها بعد ١٦ ساعة من أول قلب يُفقد. المراجعة والتدريب الحر بلا قلوب.
- هدف يومي (٣٠ نقطة)، وتدريب حر حسب العلم.
- ثلاثة أنواع من التمارين: اختيار من متعدد، وصواب أو خطأ، ومطابقة.
- السؤال الذي تخطئ فيه يعود في آخر الدرس، ويُحفظ في **المراجعة** حتى تجيبه صحيحًا.
- تُفتح الدروس والمحطات بالتتابع.
- نجوم ونقاط وأيام متتالية، وصفحة تقدّم لكل علم، ووضع ليلي.
- يُحفظ التقدّم في المتصفح (localStorage)، ولا يحتاج التطبيق إلى خادم.

## التشغيل
```bash
cd arabic && python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## إضافة المحتوى
المحتوى كله في `data.js`. ولكل درس عنوان (`title`) وفقرات شرح (`notes`) وتمارين (`qs`):
```js
M("السؤال", ["الصحيح", "خطأ", "خطأ", "خطأ"], "الشرح", "مثال يظهر بخط كبير (اختياري)")
T("عبارة", true /* صحيحة؟ */, "الشرح")
P("طابق:", [["يمين", "يسار"], ...], "الشرح")
```
الخيار الأول هو الصحيح دائمًا، وتُخلط الخيارات عند العرض.
