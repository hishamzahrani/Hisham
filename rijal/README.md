# رجال الحديث

تطبيق لتراجم رواة الحديث مرتبةً على **طبقات ابن حجر**، مع **الشيوخ والتلاميذ**، و**الجرح والتعديل** من كتب الرجال،
و**المدلسين ومراتبهم**، و**الوفيات** — وكل نص فيه **منقول من كتابه بحروفه** من «المكتبة الشاملة»، مع الجزء والصفحة.

## التطبيقان
- **`quiz/` — مسابقات رجال الحديث:** على هيئة «مسابقات قرآنية» نفسها (دروس، واختبار لكل مرحلة، وجولة ختامية لكل وحدة، وقلوب، ومراجعة الأخطاء، وتحدي صديق، واشتراك «بلس» الاختياري). المراحل هي **طبقات ابن حجر الاثنتا عشرة**، وكل ثلاث طبقات وحدة. المحاور: الجرح والتعديل، والوفيات، والشيوخ، والتلاميذ، والتدليس ومراتبه، ومن أخرج له.
  الأسئلة مولَّدة آليًّا بـ `build/quiz.py`: **الجواب الصحيح والشرح منقولان بحروفهما مع الموضع**، والخيارات الخاطئة عبارات الكتاب نفسه في رواة آخرين من الطبقة نفسها، وصيغة السؤال وحدها من التطبيق. تُختار لكل طبقة أشهر رواتها (أكثرهم ورودًا في الكتب وأوسعهم شيوخًا وتلاميذ)، والعدد بـ `--per-stage` (الافتراضي ٦٠).
  النشر على المتجرين كما في المستودع الأصلي: `npm install && npm run android` / `npm run ios` (معرّف التطبيق `ae.rijalquest.app` في `capacitor.config.json`).
- **`app/` — المكتبة:** تصفّح الرواة بطبقاتهم، وبطاقة كل راوٍ بنصوصه من الكتب كلها.

## التشغيل (على الجهاز الذي فيه المكتبة الشاملة)
```bash
./run.sh /srv/shamela
```
1. `extractor/extract.py` يقرأ نصوص الكتب من ملفات الشاملة مباشرة (قاعدة SQLite وفهارس Lucene) ويكتبها في `raw/` **حرفًا بحرف**، المتنَ دون الحواشي، مع بصمة sha256 لكل كتاب في `raw/manifest.json`. لا يمرّ النص بأي نموذج ولا يُعاد كتابته.
2. `build/build.py` يقطّع الكتب إلى تراجم ويربطها، ويكتب `app/data/`.

إن لم يجد السكربت نصوص كتاب ما فشغّل:
```bash
python3 extractor/extract.py --root /srv/shamela --inspect
```
وأرسل الناتج (بنية الجداول وأسماء الحقول فقط، بلا نصوص الكتب).

يحتاج: Python 3.8+ و Java 11+. مكتبة Lucene 9.12 مرفقة في `extractor/lib/`، و`Extract.class` مترجَم مسبقًا (يكفي JRE).

## ما المنقول وما الآلي
- **منقول بحروفه:** كل نص في إطار مظلَّل. المحذوف الوحيد إحالات الحواشي مثل (١) و(٠)، لأن الحواشي (كلام المحقق) غير منقولة.
- **آلي (ترتيب لا كلام):** الطبقة من لفظ «من العاشرة» ونحوه، وعبارة الوفاة كما هي. الفرز بالسنة يتبع قاعدة ابن حجر في المقدمة للقرن، والرقم لا يُعرض. التصفية بالألفاظ بحث حرفي. الربط بين الكتب بمطابقة الاسم والأب والجد، ويُنبَّه عند تعدد الموافق.
