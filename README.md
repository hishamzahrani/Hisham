# مسابقات قرآنية 📖

تطبيق ويب تعليمي على طريقة «دولينجو» لتعلّم معاني القرآن الكريم، في **30 جزءًا × 7 مراحل فرعية = 210 مراحل**، تبدأ من **الجزء الثلاثين** وتنتهي بـ**الجزء الأول**، بأكثر من **720 سؤالًا**.

## المراحل السبع في كل جزء
| # | المرحلة |
|---|---|
| ١ | 📖 تفسير المفردات |
| ٢ | 🕊️ أسباب النزول |
| ٣ | 💡 تفسير الآية |
| ٤ | ✨ البلاغة القرآنية |
| ٥ | 🧭 دلالة السورة والآيات |
| ٦ | 🕋 مكي ومدني |
| ٧ | 🏆 اختبار الجزء (8 أسئلة منوّعة من المهارات الست) |

تُفتح كل مرحلة بعد إتمام التي قبلها، ويُفتح الجزء التالي بعد اجتياز اختبار الجزء.

## المهارات التي يغطيها
| المهارة | مثال |
|---|---|
| 📖 تفسير المفردات | معنى «وهّاجًا»، «الصمد»، «ضيزى» + أسئلة مطابقة |
| 🕊️ أسباب النزول | عبس وابن أم مكتوم، المجادلة وخولة بنت ثعلبة |
| ✨ البلاغة القرآنية | ﴿واشتعل الرأس شيبًا﴾، ﴿والصبح إذا تنفّس﴾ |
| 💡 تفسير الآية | معنى الآية ودلالتها |
| 🧭 دلالة السورة والآيات | مقاصد السور وأسماؤها وفضائلها |
| 🕋 مكي ومدني | تصنيف السور وضوابط المكي والمدني |

## المزايا
- مسار متعرّج: لافتة لكل جزء تعرض تقدّمك (مثل ٣/٧) ثم مراحله السبع.
- 5 قلوب في كل مرحلة، والسؤال الخاطئ يعود في آخر الدرس حتى تُتقنه.
- نجوم (1–3) حسب عدد الأخطاء، ونقاط خبرة، وسلسلة أيام متتالية 🔥، وهدف يومي.
- **مراجعة الأخطاء**: تُحفظ الأسئلة التي أخطأت فيها لتراجعها.
- **التدريب حسب المهارة**: أسئلة مهارة واحدة من كل المراحل المفتوحة.
- إحصائيات إتقان لكل مهارة.
- يعمل دون إنترنت ويمكن تثبيته على الجوال (PWA)، ويدعم الوضع الليلي.
- التقدّم محفوظ في المتصفح (localStorage).

## التشغيل
لا يحتاج أي تثبيت؛ يكفي أي خادم ملفات ثابتة:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## إضافة الأسئلة أو تعديلها
المحتوى الأساسي في `js/data.js`، والأسئلة الإضافية في `js/more-1.js` … `js/more-6.js` (كل ملف 5 أجزاء)، وتُضاف بالدالة `addQ(رقم_الجزء, [...])`. تحتاج كل مهارة إلى 4 أسئلة على الأقل في كل جزء.

أدوات مختصرة:
```js
mcq("nuzul", "نص الآية", "السورة: رقم", "السؤال", ["الصحيح", "خطأ", "خطأ", "خطأ"], "الشرح")
match([["الكلمة", "المعنى"], ...], "الشرح")
tf("makki", "عبارة", true /* صحيحة؟ */, "الشرح")
makkiQ("اسم السورة", true /* مكية؟ */, "الشرح")
```
الصيغة الكاملة لسؤال الاختيار من متعدد:
```js
{ t: "mcq", c: "nuzul", a: "نص الآية", r: "السورة: رقم الآية",
  q: "السؤال", o: ["الإجابة الصحيحة", "خطأ 1", "خطأ 2", "خطأ 3"], e: "الشرح" }
```
الخيار الأول هو الصحيح دائمًا (تُخلط الخيارات عند العرض). ولأسئلة المطابقة:
```js
{ t: "match", c: "mufradat", q: "صِلْ كل كلمة بمعناها", p: [["الكلمة", "معناها"], ...], e: "الشرح" }
```

> **تنبيه:** المحتوى مكتوب بعناية من كتب التفسير وأسباب النزول المشهورة، لكن يُستحسن أن يراجعه متخصص في علوم القرآن قبل النشر العام.
